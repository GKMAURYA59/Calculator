# Maurya Calculator

A simple, fast calculator web app with keyboard support, calculation history, and dark and light views. It is a single HTML file with no installation needed.

**Live demo:** https://gkmaurya59.github.io/calculator/

## Features

- Add, subtract, multiply and divide
- Percent, plus/minus and delete
- AC to clear everything
- Keyboard support
- History of recent calculations, with a button to clear it
- Dark and light views
- Clear message when dividing by zero
- Tidy results, so 0.1 + 0.2 shows 0.3

## Keyboard shortcuts

| Key | Action |
|---|---|
| 0-9 and `.` | Enter numbers |
| `+` `-` `*` `/` | Operators |
| `%` | Percent |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete the last digit |
| `Escape` or `Delete` | Clear everything (AC) |

## Dark and light views

The calculator follows your device's dark or light setting. Click the **Dark / Light** button at the top to switch. The choice lasts until the page is reloaded.

## Run locally

There is nothing to install and no internet connection is needed. Download `index.html` and open it in any modern browser.

## Deploy on GitHub Pages

1. Create a new public repository and upload `index.html` and this `README.md`.
2. Go to **Settings, then Pages**.
3. Set **Source** to **Deploy from a branch**, choose **main** and **/ (root)**, then click **Save**.
4. After 1 to 2 minutes, your site is live at `https://YOUR-USERNAME.github.io/calculator/`.
